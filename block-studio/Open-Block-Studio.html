Before you export

Publish from a branch

  1. Merge the ZIP contents into your local repository. Review, commit and push in Tower.
  2. In Settings → Pages, choose Deploy from a branch.
  3. Select your branch and /docs (one-time setup).
  4. Register this module’s endpoint as an individual Custom Content Block in SFMC.

No custom GitHub Actions workflow or build command is needed.

Export checks cover the package and mappings. They do not certify Outlook, Gmail or SFMC rendering.
