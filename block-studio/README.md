# Block Studio

Open `Open-Block-Studio.html`, then choose **Open repository** to load the current project files.

- [User guide](../documentation/internal/USER_GUIDE.md): create, edit, test, save and recover blocks.
- [Technical guide](../documentation/internal/DEVELOPER_GUIDE.md): setup, architecture, branding, builds and releases.
- [Template syntax](../documentation/internal/TEMPLATE-SYNTAX.md): supported conditions, loops and filters.
- [ESC handover](../documentation/clients/esc/INTERNAL-HANDOVER.md): client-specific maintenance and integration.

Edit maintained source in `src/` and rebuild both application entry points. Retain tests, vendored dependencies and licence notices.
