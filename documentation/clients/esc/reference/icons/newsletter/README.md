# Full Width Image icon

The SVG master matches the established ESC icon style: #ae1022 circle, white 3px line symbol and transparent corners. Render through a real browser Canvas at 60 × 60 for icon.png and 120 × 120 for dragIcon.png. Save both PNGs in the Newsletter Full Width Image module iconAssets and export through BlockExport.files.

## Webinar List icon

The [SVG master](webinar-list.svg) uses two play markers with text lines to represent webinar rows. Render at the same two sizes. Set the red circle to 60% opacity in the drag icon, as in the supplied Newsletter icons, and keep the white symbol opaque. Store the PNG pair with the Newsletter Webinar List.
