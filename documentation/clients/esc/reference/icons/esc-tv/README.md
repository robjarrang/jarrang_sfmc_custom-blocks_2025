# ESC TV icons

Editable SVG masters for the five maintained ESC TV modules. White 3px line symbols on the same #ae1022 circle used by the supplied ESC Newsletter icons. Lead = editorial/list; Story Card = image and copy; 2 Col = paired cards; Button Row = three pills; Disclaimer = information.

Render each SVG in a real browser Canvas at 60 × 60 for icon.png and 120 × 120 for dragIcon.png, preserving transparency outside the circle. Store both PNGs in the module iconAssets and export through BlockExport.files so the project and published files remain consistent. No external fonts or dependencies are required by the SVGs.
