# ESC documentation

- [ESC Email Module User Guide (PDF)](ESC_Email_Module_User_Guide.pdf): client-facing Content Builder guide, with editor controls and visual references for all 47 content modules: 29 Newsletter, 13 Congress and 5 ESC TV. Includes the shared Email settings workflow, Full Width Image and link tracking options. Updated 14 November 2026; 20 pages with bookmarks.
- [Internal maintenance handover](INTERNAL-HANDOVER.md): for Jarrang developers, not client distribution.
- [Module inventory](reference/ESC-Block-Studio-Modules.xlsx): supplied historical reference; use Studio for current fields and modules.
- [SFMC integration instructions](../../../integrations/esc/email-settings/README.md): install the shared Email settings block and setup snippet.
- Editable icon masters: [ESC TV](reference/icons/esc-tv/README.md) and [Full Width Image](reference/icons/newsletter/README.md).

The PDF is the guide for people composing emails in SFMC. The [internal Studio user guide](../../internal/USER_GUIDE.md) covers creating and maintaining blocks. Keep the PDF and its page references/bookmarks current when module controls or the inventory change. Its screenshots are illustrative previews, not certification of SFMC or email-client rendering.
